DSH Desktop упаковывает локальный DeepSeek Harness в устанавливаемое настольное приложение. Оно автоматически запускает Harness, хранит профили, плагины, рабочие пространства, настройки моделей и сеансы вне каталога установки и открывает полный интерфейс Harness, как только локальная среда выполнения готова.

> [!IMPORTANT]
> DSH Desktop — ранняя предварительная версия на основе быстро развивающегося `@deepseek-ai/dsh@0.2.1-rc.4`. Установщик для Windows x64 — неподписанная общественная сборка, поэтому при первом запуске Windows SmartScreen может показать предупреждение. Проект не является официальным продуктом DeepSeek.

## Загрузка

Скачайте последний `dsh-desktop-windows-x64-setup.exe` на странице [GitHub Releases](https://github.com/LightyearXizIl/DSH-Desktop/releases). Версии с отметкой **Pre-release** предназначены для ранних испытателей и могут быть несовместимы с некоторыми общественными плагинами.

Установленное приложение проверяет обновления на GitHub Releases вскоре после запуска и каждые шесть часов. Найдя новую версию, DSH Desktop сначала спрашивает разрешения и показывает список изменений этого выпуска; загрузка начинается только после согласия, а установка — только после выбора «Перезапустить и установить». Проверить обновления можно и вручную в разделе «Настройки → О программе», а также пропустить одну версию, не отключая уведомления о следующих.

## Что добавляет DSH Desktop

DeepSeek Harness уже предоставляет среду выполнения агентов и веб-интерфейс. DSH Desktop добавляет к ним возможности настольного приложения:

- Автоматический запуск и остановка Harness без отдельного CLI или вкладки браузера
- Добавление рабочих пространств проектов и управление ими через системный диалог выбора папки
- Поддержка официальных моделей DeepSeek и популярных сторонних поставщиков моделей
- Импорт и экспорт пользовательских Agent Preset в виде переносимых [архивов `.dshpreset`](docs/preset-packages.md) с проверкой конфликтов имён и предупреждением о доверии перед установкой
- Создание редактируемых PPTX из материалов во встроенном режиме PPT
- Встроенные Python и библиотеки Office для автономного создания и проверки DOCX, PPTX и XLSX
- Сохранение профилей, плагинов, рабочих пространств, сеансов и настроек моделей при обновлении приложения
- Обнаружение сбоев запуска Harness и фронтенд-плагинов, запись диагностики в `harness.log` и пошаговое восстановление
- Безопасный режим, который временно отключает сторонние плагины, не повреждая данные пользователя
- Продолжение сеансов с сопряжённого телефона по локальной сети или через необязательный временный публичный туннель
- Встроенная тема Liquid Glass (режимы Mica и совместимости), анимация запуска и необязательный автозапуск локальной модели
- Проверка обновлений прямо в приложении; решение о загрузке и установке остаётся за пользователем

## Создание PPT

Нажмите кнопку **PPT**, выберите шаблон и опишите, что нужно сделать. Встроенный каталог содержит **16 шаблонов и 192 макета** и создаёт редактируемые PPTX. Предпросмотр шаблонов показывается на английском; содержимое можно создавать на китайском и английском с соответствующими настройками шрифтов, а язык предпросмотра не определяет язык результата.

Функция PPT всегда предустановлена, а связанные с ней автоматические подсказки действуют только в сеансах, где выбрана кнопка PPT. Шаблоны, проверки и источники описаны в [заметках о PPT](packages/ppt-runtime/README.md).

## Подключение телефона

Выберите «Подключить телефон…» в меню `Harness` и отсканируйте QR-код сопряжения.

- В сети Wi-Fi достаточно отсканировать код.
- Для интернет-туннеля нужно также ввести 6-значный пароль, показанный на компьютере. По умолчанию это временный пароль на 5 минут, хранящийся только в памяти; постоянный пароль создаётся на компьютере лишь после вашего согласия в окне «Подключить телефон».

Сам Harness всегда работает на случайном порту `127.0.0.1`, а доступ с телефона идёт через отдельный мост сопряжения. Cloudflare Quick Tunnel — основной путь для долгого подключения. Бесплатный Pinggy служит резервным каналом, когда Cloudflare недоступен (например, в материковом Китае), и перестаёт работать примерно через 60 минут. После отключения на компьютере сеанс на телефоне завершается.

Если Cloudflare не запускается, используется Pinggy. Если ссылка Cloudflare показана, но телефон не может её открыть, нажмите «**Не открывается? Другая линия**», чтобы переключиться на Pinggy.

## Безопасный режим и восстановление

Если сторонний плагин нарушает запуск или отображение интерфейса, DSH Desktop по данным среды выполнения и фронтенда определяет виновный плагин и открывает пошаговую страницу восстановления.

Пункт «Перезапустить в безопасном режиме…» в меню `Harness` запускает изолированный профиль только с официальными базовыми Bundle. Сторонние плагины обычного профиля отключаются, но агенты, сеансы, настройки моделей и рабочие пространства остаются доступны. Из баннера безопасного режима можно удалить выбранный проблемный плагин или вернуться к обычному запуску. Страница восстановления также проверяет совместимые обновления плагинов, а безопасный режим поддерживает пакетное обновление.

Если обычный интерфейс не открывается, приложение можно запустить с ключом `--safe-mode`, например в PowerShell:

```powershell
& "$env:LOCALAPPDATA\Programs\DSH Desktop\DSH Desktop.exe" --safe-mode
```

(Если приложение установлено в другую папку, укажите фактический путь.)

## Локальные данные и безопасность

- Веб-интерфейс Harness работает только на случайном loopback-порту.
- Renderer не имеет доступа к Node.js и работает с Context Isolation и Sandbox.
- WebView, недоверенные переходы внутри приложения и неожиданные запросы разрешений блокируются.
- Внешние веб-ссылки открываются в системном браузере.
- Профили и сеансы хранятся в пользовательском каталоге данных приложения Electron, а не в каталоге установки.
- Для доступа с телефона нужен кратковременный токен сопряжения. В Wi-Fi достаточно отсканировать код; для интернет-туннеля дополнительно нужен пароль с компьютера.

## Поддерживаемые платформы

| Платформа | Формат | Статус |
| --- | --- | --- |
| Windows x64 | Неподписанный установщик NSIS | Поддерживается |
| macOS | Скрипты сборки сохранены в исходниках, установщики не публикуются | Не публикуется |
| Windows ARM64 / Linux | — | Пока не поддерживается |

Harness содержит нативные зависимости для каждой платформы, поэтому каждый установщик нужно собирать на соответствующей операционной системе и архитектуре.
